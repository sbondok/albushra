
# دليل التشغيل والتحقق (Walkthrough)

## 1. مقدمة
هذا الملف يوثق خطوات التحقق من الميزات التي تم بناؤها في نظام **تحصيل - مدارس البشرى**.

## 2. الميزات المنجزة
### أ. استيراد البيانات
- **الرابط:** `/upload`
- **الوظيفة:** رفع ملف Excel يحتوي على الفواتير والطلاب.
- **التحقق:**
    1. ارفع ملف `.xlsx`.
    2. تأكد من ظهور المعاينة.
    3. اضغط "استيراد" وتأكد من الرسالة الخضراء.

### ب. إدارة أولياء الأمور
- **الرابط:** `/guardians`
- **الوظيفة:** بحث وعرض قائمة أولياء الأمور.
- **التحقق:** ابحث برقم هوية أو اسم.

### ج. الملف المالي والدفعات
- **الرابط:** `/guardians/[ID]`
- **الوظيفة:**
    - عرض المبالغ المستحقة.
    - عرض الفواتير الملونة حسب الحالة.
    - **زر "تسجيل دفعة":** يفتح نافذة منبثقة.
- **التحقق:**
    1. سجل دفعة بمبلغ جزئي (مثلاً 500 ريال).
    2. لاحظ تغير المبلغ المستحق فوراً.
    3. لاحظ تغير حالة أقدم فاتورة إلى "جزئي" أو "مسدد".

### د. سندات القبض
- **الرابط:** عبر جدول الدفعات -> "عرض السند".
- **الوظيفة:** صفحة A4 جاهزة للطباعة تحتوي تفاصيل التوزيع وشعار المدرسة.
- **التحقق:** اضغط زر الطباعة وتأكد من ظهور الشعار (من ملف `public/logo.png`).

### هـ. عرض وطباعة الفواتير
- **الرابط:** عبر جدول الفواتير -> اضغط على رقم الفاتورة.
- **الوظيفة:** عرض تفاصيل الفاتورة مع زر للطباعة.
- **التحقق:**
    1. اضغط على رقم فاتورة في القائمة.
    2. تأكد من ظهور التفاصيل والترويسة (من ملف `public/heading.png`).
    3. اضغط "طباعة الفاتورة".

### هـ. التقارير (Query Builder)
- **الرابط:** `/reports`
- **الوظيفة:** فلترة الحسابات.
- **التحقق:**
    1. اختر الحالة "متعثر".
    2. حدد مبلغ أكبر من 1000.
    3. اضغط "بحث" ثم "تصدير CSV".

### و. الأمان وإدارة المستخدمين (Security) 🔐
- **الدخول:** `/login`
- **الوظيفة:** حماية النظام من الاستخدام غير المصرح به.
- **الحسابات الافتراضية:**
    - **المدير:** `admin` / `admin123` (صلاحيات كاملة)
    - **المشاهد:** `viewer` / `viewer123` (قراءة فقط)
- **أدوات سطر الأوامر (Terminal):**
    - إنشاء مستخدم: `npm run create-user <user> <pass> <role>`
    - تغيير كلمة المرور: `npm run change-password <user> <new-pass>`
